# Our Story Continues

An interactive five-chapter birthday surprise built with React, Vite and Framer Motion.

## Personalize first

Edit `src/data/birthdayData.js`. It contains the name, verification answers, every photo path, caption, final letter, and final messages.

Put your assets in these folders:

- `public/images/childhood/`
- `public/images/teenage/`
- `public/images/growing-up/`
- `public/images/marriage/`
- `public/images/us/`
- `public/audio/` (optional `emotional-music.mp3` and `heartbeat.mp3`)

Missing images show an elegant placeholder and missing audio silently falls back, so the site remains usable while you add materials.

## Run it

```bash
npm install
npm run dev
```

Then open the local address Vite prints in your browser.
